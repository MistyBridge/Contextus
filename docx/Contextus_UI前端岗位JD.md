## 一、我们是谁，要做什么

**Contextus** 是一个面向 AI Agent 的「会话状态运行时」：用户与 AI Agent 的**每一轮交互自动成为一个 git commit**（代码 + 对话 + 审计日志的世界快照），会话呈**树形结构**——任意历史节点可以分支（多条世界线并行）、可以回溯（回到任意时刻继续）、可以双向追溯（代码提交 ↔ 产生它的对话）；一套版本化规则全局生效。

MVP（命令行 + 终端 TUI）已全部跑通并经真实窗口验收。**现在要把它变成一个有「炫酷感」的图形界面**——让用户可视化地浏览世界线树、管理分支、操作会话。

你负责的正是这件事。

## 二、岗位职责

1. **设计并实现树形会话管理 UI**（本地 Web 应用形态：浏览器打开，本地服务）
2. **视觉与交互设计**：这是硬要求——动画流畅、深/浅主题、终端质感，对标现代 devtools（Linear / Raycast / Warp）的审美水准
3. **与现有 TypeScript 核心层对接**：核心逻辑、数据读取全部已实现，你负责把它们「前端化」
4. **数据可视化**：世界线树、commit 时间线、审计日志流、规则版本演进
5. **终端集成**：从 UI 触发打开真实终端窗口运行 AI 会话（唤起逻辑已实现）

## 三、需要被前端表现出来的功能（现状盘点）

以下每一项**后端逻辑均已实现并实测**，前端只需对接：

| # | 功能 | 现有实现 | 前端呈现要求 |
|---|------|---------|-------------|
| 1 | **世界线树** | 会话节点、世界线指针（refs/context）、tip/孤儿节点，全部可从 git 历史索引 | 树形布局：世界线分组、父子层级、tip 高亮、孤儿分支灰显、分支分叉点可视化 |
| 2 | **节点操作** | 进入节点（物化上下文 → 开真实终端跑 claude）、查看模式（checkout 代码世界）、回溯即分叉（自动建新世界线） | 节点点击：详情面板 + 操作菜单（进入 / 查看 / 从这分叉） |
| 3 | **代码世界** | `diff <节点A> <节点B>`：两个会话之间代码差异（git diff） | side-by-side 代码 diff 渲染（语法高亮） |
| 4 | **双向追溯** | `find <commit>` → 产生它的会话；节点 → 对应 commit | commit 徽章可点击跳转节点；节点可跳转 commit |
| 5 | **规则管理** | `policy set/show/log`：版本化规则（git 历史），全局生效（CLAUDE.md 通道，实测「看不到但生效」） | 规则编辑器 + 版本历史时间线 + diff 视图 |
| 6 | **维护操作** | `rename`（改世界线 tip 名称，审计记录）、`drop`（废弃世界线，节点仍可索引） | 内联改名、二次确认的废弃操作 |
| 7 | **实时状态** | 文件监控自动提交（每检测到新提问 → 提交上一轮）；工作区状态；世界线指针 | 提交事件实时推送进 UI（状态灯/通知/toast） |
| 8 | **审计时间线** | 运行日志（runtime.log 事件流：轮开始/提交/规则变更/维护操作）+ git 历史互证 | 时间线视图：会话事件与 commit 交错展示，可筛选类型 |
| 9 | **统计视角** | 每轮 token 用量记录在会话文件中（usage 字段，已入库） | 每节点/世界线的 token 成本汇总（可选，数据已在） |

## 四、技术上下文（已有基础）

- **核心层**：TypeScript / Node.js（22 LTS），CLI `sm` 已具备全部命令；逻辑模块化（twin / policy / sessions / records / git 封装）
- **数据来源**：git 对象库（历史即索引）、`.contextus/`（会话世界文件）、`~/.claude/projects`（AI 会话文件）——**全部已封装好读取函数**
- **对接方式（由你选择，建议 A）**：
  - A. 本地 Node 服务 + 前端（同一 TS 仓库），服务直接复用核心模块，前端 React/任意现代栈
  - B. 纯前端 + 直接调用 CLI 命令（子进程）
- **平台**：Windows 11 优先（终端唤起、路径编码等坑已在核心层解决，前端无需关心）
- **加分项**：git 图形化经验（如 GitKraken/SourceTree 类产品）、终端模拟器（xterm.js）、动效设计（framer-motion 类）、数据可视化（D3/ECharts）

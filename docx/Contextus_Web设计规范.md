# Contextus Web 设计规范 v1.0（M1）

> 2026-08-14 · UI前端工程师 · 状态：**待评审**（评审通过后作为 M1~M4 的视觉契约）
> 上游：Web 前端技术方案 v1.0（D6 已拍板：GitKraken 式图形化）

## 0. 设计定位

- **Design Read**：密集 devtool 产品 UI（AI 会话世界线管理），面向 agent 重度用户；GitKraken 式图形化语言：浅色优先、世界线品牌色区分、明快图形、圆润卡片；走自定义 Tailwind tokens + React Flow 画布 + 克制动效。
- **Dials**：DESIGN_VARIANCE 4（产品 UI 结构一致性优先）· MOTION_INTENSITY 4（仅状态转换动效，打磨留 M4）· VISUAL_DENSITY 7（cockpit 密度：sha/时间/分支名全可见）。
- **范围声明**：本项目是密集产品 UI（非营销页），taste-skill 的落地页规则（hero/eyebrow 等）不适用；**适用并强制**的部分：token 纪律、字体纪律、色彩校准、动效动机、状态完备性（loading/empty/error）、a11y 对比度。

| `--text` | `#1A1D23` | `#E6E8EC` |
| `--text-2` | `#5A6072` | `#9AA1AC` |
| `--text-3` | `#8A90A0` | `#6B7280` |

无纯黑 `#000`、无纯白 `#FFF`（skill 9.A）。

### 1.2 世界线配色（用户拍板 2026-08-14：不按世界线名写死颜色）

~~按 refs 顺序循环取 6 色~~（废除：`main` 蓝 / `main-2` 紫的按名配色太武断）。

**现行规则**：

- **全部 tip 节点（各世界线的叶）统一 `--ok` 绿**（light `#10B981` / dark `#34D399`）——绿 = 唯一活跃高亮语义
- **非 tip 节点中性色**：常规卡片描边，无世界线色
- **车道导线 / 列头 / 边线**：中性灰 `--text-3`（40-60% 透明度），fork 弧线与 continue 直线靠形状区分
- **孤儿世界线**（ref 已 drop）：恒灰 `#9CA3AF` + 虚线列头 + 节点 60% 透明度

### 1.3 语义色（少量、有实义）

| token | 值 | 用途 |
|-------|-----|------|
| `--ok` | `#10B981` | 状态灯 watching / tip 徽章 |
| `--warn` | `#F59E0B` | 窗口进行中 / 提示 |
| `--danger` | `#EF4444` | failed 节点 / 错误 toast |
| `--accent` | `#3B82F6` | 主操作按钮（唯一强调色，全页一致） |

状态点仅用于**真实语义**（watching/窗口/failed），零装饰点（skill 9.F）。

## 2. 字体系统

- **UI 无衬线**：Outfit（圆润现代，契合「圆润卡片」方向）+ CJK 回退 `Microsoft YaHei` / `PingFang SC`（Windows 11 优先）
- **等宽**：JetBrains Mono —— sha 徽章、分支名、时间戳、commit 名
- 自托管 `@fontsource`（无 Google Fonts 外链），`font-display: swap`
- 字号阶梯（DENSITY 7，紧凑）：`11`（sha/徽章）· `12`（meta/时间）· `13`（正文）· `14`（卡片标题）· `16`（面板标题）· `20`（顶栏品牌）

---

## 3. 形状与阴影（Shape Consistency Lock）

单一半径体系（有文档化规则）：

| 元素 | 半径 |
|------|------|
| 卡片/面板 | `10px` |
| 按钮/输入框 | `8px` |
| 徽章/状态点 | 全圆 pill |

- 阴影：仅浅色主题、贴背景色相（`0 1px 2px rgba(16,24,40,.05)`，浮层 `0 8px 24px rgba(16,24,40,.10)`）；**无纯黑投影**
- 描边优先于投影：层级主要靠 `--border` 细线区分（GitKraken 风格）

## 4. 动效规范（M1 范围）

MOTION 4：**每个动效必须能一句话说明动机**（反馈/状态转换），M4 再整体打磨。

| 动效 | 动机 | 规格 |
|------|------|------|
| 节点选中 | 反馈 | 描边环 + spring（stiffness 100, damping 20） |
| 新 commit 到达 | 状态转换 | 车道线向下生长 240ms + toast 滑入 |
| fork 弧线绘制 | 讲述（分叉叙事） | 树加载时按行序错峰 draw-in（每行 40ms） |
| 按钮按压 | 反馈 | `scale-[0.98]` |

硬约束：只动 `transform/opacity`；`prefers-reduced-motion` 全部降级为静态；不用 `window.addEventListener('scroll')`。

## 5. M1 界面快照

### 5.1 主界面（light，默认）

```
┌────────────────────────────────────────────────────────────────────────────┐
│ ◈ Contextus   D:\dev\my-app                 ● watching   [main]      🌙 ⚙ │  顶栏 56px
├───────────────────────────────────────────────┬────────────────────────────┤
│                                                │  节点详情                   │
│   main       main-2        exp     (orphan)    │  ┌──────────────────────┐   │
│   ━━━━━      ━━━━━         ━━━━━   ┅┅┅┅ 灰虚线  │  │ 把 API 改成异步       │   │
│   ● 蓝        ● 紫          ● 琥珀   ○ 灰      │  └──────────────────────┘   │
│   │           ╱             │                  │  branch  main-2            │
│   ● ─────────╳──╮           │                  │  decision  fork ⑂         │
│   │           │  ╰──────→ ● │ ← fork 弧线       │  sha  9f2a31c  (mono)      │
│   ● tip★      ● tip★        │                  │  created  08-14 15:02      │
│   │(绿色徽章) │              │ tip★             │  ────────────────────      │
│   └           └              └                  │  [ 进入节点 ]  [ 查看模式 ]  │
│   ← 车道列头 = 分支名 + 彩点 →                   │  ☐ 同步最新代码             │
│   ← 节点卡片：前20字 + decision 图标 + sha      │                            │
├───────────────────────────────────────────────┴────────────────────────────┤
│ 15:02:11 commit 9f2a31c → main-2 · 14 条记录        ▲ toast 区（可收起）      │
└────────────────────────────────────────────────────────────────────────────┘
```

要点：
- 车道 = 世界线垂直导线（中性灰），tip 节点统一绿色描边 + tip 徽章，孤儿列灰显
- fork 弧线从父节点右侧引出、跨列到子车道（子车道列头旁标 `⤷ from main`）
- 节点卡片默认只显示前 20 字；选中态展开详情（右侧面板同步）

### 5.2 dark 主题

同 token 派生：`--bg #0E1116`、tip 绿 `#34D399`、中性线提亮一档；**层级完整保留，不做亮度反转牺牲**。

### 5.3 状态完备（skill 强制）

| 状态 | 形态 |
|------|------|
| loading | 车道骨架屏（车道线 + 节点位置占位 shimmer），非转圈 |
| 空树 | 画布中央引导卡：`尚未启用 Twin` + `sm twin-init` 命令（等宽 + 复制按钮） |
| 窗口进行中 | 底部面板：世界线名 + 状态灯 amber + 「在其中提问；关闭窗口后回到此提交」 |
| 错误 | toast（danger）+ 画布内联错误条（脏工作区列出前 3 个文件） |

## 7. 反模板纪律（逐条落实）

- ✅ 无 AI 紫渐变 / 玻璃拟态滥用 / 三列等宽卡片模板
- ✅ 无纯黑纯白；中性冷灰基调，唯一强调色 accent 蓝
- ✅ 车道多色是**产品语义**（世界线区分），非装饰渐变
- ✅ 状态点只表真实状态；等宽字体只用于 sha/分支/命令
- ✅ 按钮对比度 WCAG AA（浅色主题 accent 蓝底白字 4.5:1）
- ✅ 双主题同源 token，启动即测两态
- ✅ 可见文案零 em-dash 装饰、零 AI 腔（如「优雅的」「无缝的」禁用）
